# 萤石 LAN 录像下载

在本机浏览器导出萤石摄像头 SD 卡上的历史录像。可以勾选多台相机，按北京时间选择开始和结束整点。任务按提交顺序单路执行，页面显示已处理片段、已保存数量、失败数和最近一段的平均速度。

## 安装与使用

1. 安装 Python 3.12 或更新版本。在项目目录运行 `python -m pip install -r requirements.txt`。
2. 复制 `devices.example.json` 为 `devices.local.json`。每台相机填写 `name`（页面显示名）、`host`（局域网 IP）和 `serial`（设备序列号）。设备配置名可用英文字母、数字、下划线和连字符。
3. 确认电脑能连接相机所在的局域网，运行 `python server.py`，然后打开 <http://127.0.0.1:8765/>。
4. 选择时间、勾选相机，输入对应的设备验证码，再点「加入任务队列」。例如，选择同一天 08:00 到 20:00 可导出这 12 小时内的录像。若要覆盖一整天，结束时间选次日 00:00。

## 文件与任务

MP4 默认保存到 `recordings/<设备配置名>/<录像日期>/`。可用 `EZVIZ_H5_OUTPUT` 环境变量指定其他目录。刷新页面可以继续查看任务，重启服务会清空队列。设备验证码只在运行时使用。

遇到失败片段时，等任务结束后重新提交相同的设备和时间范围。程序会跳过已保存的片段。若无法读取录像目录，先确认设备地址、序列号和验证码，再检查萤石客户端能否回放同一时段的 SD 卡录像。

服务只监听本机。请将设备配置、验证码和录像保留在本地。
